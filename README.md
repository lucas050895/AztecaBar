<div align="center">
  <h1>📊 AZTECA BAR</h1>
  <p><strong>Sistema de Gestión Gastronómica</strong></p>
  <hr />
</div>

<p align="justify">
  <strong>AztecaBar</strong> es una aplicación web desarrollada en <strong>PHP</strong> diseñada para optimizar la operativa diaria de establecimientos gastronómicos. El sistema integra el control de mesas, la gestión de pedidos y la comunicación directa con terminales de impresión para agilizar el servicio.
</p>

<h2>🛠 Funcionalidades Principales</h2>
<ul>
  <li><strong>Gestión de Comandas:</strong> Registro ágil de pedidos vinculados a mesas específicas o despacho directo en barra.</li>
  <li><strong>Impresión Térmica (ESC/POS):</strong> Integración nativa con el driver <code>escpos-php</code> para la emisión automatizada de tickets de cocina y facturación.</li>
  <li><strong>Administración de Catálogo:</strong> Control dinámico de productos, precios y categorías para una actualización rápida de la carta.</li>
  <li><strong>Seguridad y Acceso:</strong> Gestión de sesiones para proteger el acceso administrativo y delimitar funciones del personal.</li>
</ul>

<h2>📋 Stack Tecnológico</h2>
<p>
  <code>PHP 8.x</code> 
  <code>MySQL / MariaDB</code> 
  <code>Escpos-PHP Driver</code> 
  <code>HTML5 / CSS3</code> 
  <code>JavaScript (ES6+)</code> 
  <code>Apache Server</code>
</p>

<h2>📂 Estructura del Proyecto</h2>
<pre>
AztecaBar/
├── php/actions/         # Lógica de controladores y DB
├── lib/escpos-php/      # Driver de impresión térmica
├── assets/              # CSS, JS y recursos visuales
└── index.php            # Punto de entrada del sistema
</pre>
